# Demo Script (2 экрана)

## Цель
Показать, что MVP выглядит готовым к запуску: поиск по сходству, переписка, анонимный режим и сценарий раскрытия.

## Подготовка
- Запустить backend (`backend`) и мобильное приложение (`myapp`).
- Подготовить два устройства (или устройство + эмулятор).
- Войти под двумя аккаунтами:
  - Пользователь A: `andrey` / `password123`
  - Пользователь B: `dasha` / `password123`

## Сценарий записи (рекомендуемый порядок)
1. **Поиск по сходству**
   - На экране поиска показать карточки с `Сходство: X%`.
   - Открыть профиль собеседника из карточки.

2. **Старт анонимного чата**
   - Нажать `Анонимный матч по сходству`.
   - В чате показать:
     - блок `Общие интересы`,
     - блок `Подсказки для старта`.

3. **Диалог с двух экранов**
   - На экране A отправить сообщение.
   - На экране B показать, что сообщение появилось (автообновление раз в несколько секунд + pull-to-refresh).
   - Отправить ответ с экрана B и показать его на экране A.

4. **Сценарий раскрытия (основной flow)**
   - На экране A через меню выбрать `Показать анкету` и отправить запрос.
   - На экране B показать модалку с выбором:
     - `Принять` (показывает успешное раскрытие),
     - или `Отклонить` (переход к следующему пункту).

5. **Сценарий после отклонения**
   - Если B отклоняет запрос, на экране A появляется вопрос:
     - `Продолжить анонимно` или `Удалить чат`.
   - Показать оба варианта в двух дублях записи:
     - дубль 1: продолжение анонимного диалога,
     - дубль 2: автоудаление диалога.

## Что важно поймать в видео
- На старте чата есть подсказки и общие интересы.
- Интерфейс выглядит цельно на мобильном.
- Анонимность работает по согласованной бизнес-логике.
- Переходы между состояниями понятны без пояснений за кадром.
